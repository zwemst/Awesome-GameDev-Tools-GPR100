# Awesome-GameDev-Tools-GPR100
A list of tools for game development that I have researched
## Tools
- Blender
http://www.blender.org/ is a free open source 3D creation suite, from modeling to rendering
- Audacity
http://sourceforge.net/projects/audacity/ is a tool for manipulating and editing audio, as well as recording it
- Godot
https://github.com/godotengine/godot is a free open source C# game engine
- Open Source Game Clones
http://osgameclones.com/ is a collection of open source versions of older games, good for looking at how systems work in certain games to learn from
- Box2D
http://box2d.org/about/ is an implementation of rigid body physics in C++
- Gamesounds.xyz
https://gamesounds.xyz is a collection of royalty free music and sounds, with various licenses, some of which are free
- Open Font Library
https://fontlibrary.org is a collection of freely licensed fonts
- Visual Studio Code
https://code.visualstudio.com/ is a Free IDE owned by Microsoft that supports any language, from HTML to C++
- Piskel
http://www.piskelapp.com/ is a free online pixel art editor
- GIMP
http://www.gimp.org/ GNU Image Manipulation Program, or GIMP for short, allows you to edit and manipulate, as well as create images.
